Dokumentasi API QRISPay

Integrasi untuk bot / website. Autentikasi via header x-api-key.

Base URL

Buat QRIS

POST /api/v1/qris — x-api-key

POST /api/v1/qris
x-api-key: qp_xxx
Content-Type: application/json

{ "amount": 10000, "provider": "gopay", "reference": "INV-1", "callback_url": "https://yourbot/webhook" }

→ 201
{ "success": true, "data": { "qris_id": "...", "qris_code": "000201...", "qr_url": "/qr/...", "amount": 10021, "expires_at": "..." } }

amount = nominal dasar (base). Gateway menambahkan kode unik (21–200) untuk matching. provider opsional — kalo di-omit, dipilih otomatis sesuai tier langganan. Hanya provider yang diizinkan tier Anda yang bisa dipakai.

Cek Status (polling)

GET /api/v1/qris/:id/status — publik

GET /api/v1/qris/{qris_id}/status

→ 200 { "success": true, "paid": false, "status": "PENDING" }
→ 200 { "success": true, "paid": true, "status": "PAID", "transaction": {...} }
→ 410 { "success": false, "status": "EXPIRED" }

Polling tiap 3–5 detik. Saat PENDING, gateway otomatis fetch mutasi provider dan coba settle. Tidak perlu webhook, tapi disarankan pakai webhook untuk reliabilitas.

Akun & Saldo

GET  /api/v1/me              x-api-key  → subscription + allowed_providers + balance
GET  /api/v1/balance         x-api-key  → { balance, held, available }
POST /api/v1/withdraw        x-api-key  → { amount, bank_detail: { bank_name, account_number, account_name } }
GET  /api/v1/withdrawals     x-api-key
GET  /api/v1/transactions    x-api-key
GET  /api/v1/ledger          x-api-key  → audit trail

Webhooks

GET    /api/v1/webhooks      x-api-key
POST   /api/v1/webhooks      x-api-key  → { url, secret?, events?: ["payment.success"] }
DELETE /api/v1/webhooks/:id  x-api-key

Event payment.success dikirim ke URL Anda dengan signature X-Webhook-Signature: sha256=... (HMAC-SHA256 dari body). Verifikasi:

const crypto = require('crypto');
const sig = 'sha256=' + crypto.createHmac('sha256', secret).update(rawBody).digest('hex');
crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(req.headers['x-webhook-signature']));

Health

GET /api/v1/healthz → { "status": "healthy" }

Tier & Provider

  • H+1 (ShopeePay) — gratis, untuk semua user. Settlement H+1.
  • H+0 (GoPay) — khusus langganan berbayar. Settlement H+0 (lebih cepat cair).

Provider lain selain yang diizinkan tier → 403 PROVIDER_NOT_PERMITTED.
